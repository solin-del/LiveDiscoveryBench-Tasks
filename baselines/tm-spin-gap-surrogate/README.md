# Archived B3LYP gap baselines on generated VSS geometries

The task uses 173 training, 45 development and 103 final VSS records (173/44/101 disjoint elemental-formula groups). It predicts the archived B3LYP/def2-TZVP vertical E_HS(R_HS)-E_LS(R_HS) at source B3LYP high-spin optimized geometries, LANL2DZ metal/6-31G* other atoms. This generated-geometry B3LYP task changes both the dataset and protocol of the earlier crystal-geometry B3LYP* candidate. It does not resolve the old crystal-coordinate redistribution scope.

The primary reference anchor is the three-seed geometry MLP, selected by the lowest development MAE across the compared families: MLP 7.548646368247669 versus trees 7.556141943441921 and KRR 7.991817031937034. Final MAE is 7.793858458391523 kcal/mol; the training-median bottom anchor is 15.373565448535388. Trees score 5.077471566282976 and KRR 9.51154966312888. The lower tree final score does not make trees the development-selected overall winner. These independent geometry baselines are not a reproduction of published SLATM/SOAP/MACE/3DMol networks or a claim of current SOTA.

The descriptor reads only element counts, metal identity, total charge, comparison multiplicities, element-resolved metal radial moments and a zero-padded Coulomb-matrix eigenvalue spectrum. Features are fitted and standardized on training only; configurations are selected on development only. The MLP uses hidden layers (256,128), alpha=0.01, seeds 61041/61042/61043 and a 500-iteration cap. One member reaches that cap; global convergence is not claimed. Frozen NPZ assets contain plain numeric arrays, not author pickles. The tree inference casts input to float32 to match sklearn.

Run `python recipe/rebuild.py --training /path/to/task/input/data/training.json --development /path/to/task/input/data/development.json --output /new/output`. Pin numpy 2.3.2, scipy 1.17.1, scikit-learn 1.7.2 and threadpoolctl 3.7.0, one thread. The recipe reads no final records or labels. Every frozen numerical asset has been rebuilt from the public inputs with zero array difference; separate inference comparisons allow numerical roundoff. Submit the directory containing solution/, without measured/results or this README.

The two comparison states follow Duan source Methods: d3/d7=(2,4), d4/d6=(1,5), d5=(2,6), for Cr/Mn/Fe/Co in oxidation states II/III. The d4 singlet is a source comparison convention; the intermediate triplet is not evaluated and no universal d4 low-spin or complete ground-state assignment is made. Source single-point singlets are restricted and non-singlets unrestricted. Per-record source HS metadata, charge and electron parity are checked without target signs. Raw electronic job outputs and all source numerical settings have not been independently rerun.

Final labels are 103 negative/0 positive/0 zero; training 166/7/0 and development 43/2/0. The two source-test positive labels were excluded by the predeclared P2/P3 formula rule. No target-driven split repair is made. A constant negative model has perfect final sign accuracy, so the current task scorer omits that non-discriminating diagnostic and retains continuous MAE. Formula grouping is conservative, not certified complete molecular identity. P1/P5 final records may overlap; source targets were publicly released and inspected during construction, so this is not a pristine hidden holdout. The optimized geometry itself requires prior quantum preparation; no end-to-end DFT replacement saving is measured.

The current scorer passes offline Linux inference and trusted scoring for all three models and the training median, six malformed responses, a target-free isolation-boundary probe, and deterministic tree replay. The replay explicitly verifies that the non-discriminating sign diagnostic is absent; all retained metrics match the earlier local scorer equivalence check. measured/linux_report.json and measured/results/ contain this final replay. Its archive checksum and scorer bytes were independently matched to the reviewed candidate and committed task scorer. Compatibility tests use a CPU Docker image and a construction-only public-API VerifyContext double, not the private operator image/SDK. Actual operator SDK/image and root/chroot/setuid/syscall-isolation capability require technical review before merge. Missing isolation fails closed. Inference has 1800 s wall and 4 GiB address-space caps, is single-process/offline, and has no final references or VerifyContext state in its filesystem.
