# Archived documented116 VSS method-selection baselines

The conditional VSS-only cohort has 117 labelled training and 58 final records in 117/57 disjoint elemental-formula groups. It selects one of 45 fixed method columns to minimize gap error against the archived approximate DLPNO-CCSD(T0) reference. The density_mean_std reference is training-formula-group-CV selected, with final MAE 2.6460461241067943 kcal/mol. The training-selected fixed method m06-l_hfx_30 supplies the bottom anchor 3.163990678933186; geometry_charge MAE is 3.0180903363003124 and the oracle lower bound is 0.4183947155527795. These are results on this new cohort, not the original 181-channel network or paper test scores.

The chosen view has 3339 dimensions: actual-element counts plus raw116 channel means/stds, appended to the same 77-dimensional structure/charge descriptor. Each raw116 input consists of source PBE0 alpha and beta HS-LS density-difference shell-power spectra, 58 zero-padded channels per spin block. The original all-VSS atom-type normalization is inverted; target scaling uses training only. The predictor is a 256-tree multi-output ExtraTrees ensemble, seed 20260930, n_jobs=1, leaf=1, max_features=0.5, predicting absolute error per allowed method. Take the first minimum in the fixed registry. Geometry-only uses leaf=8, max_features=0.5. Formula-group CV froze the selected view/configuration before v2 final scoring; previous public-source targets and earlier v1 pilot results had already been inspected.

Run `python recipe/p5_defined_rebuild.py --training /path/to/task/input/data/training.json --recipe recipe/frozen_recipe.json --output /new/output`, with numpy 2.3.2, scipy 1.17.1, scikit-learn 1.7.2, threadpoolctl 3.7.0 and one numerical thread. The self-contained recipe reads training only and performs no model search. All exported arrays rebuild with zero numerical difference. Submit the directory containing solution/; measurement JSON is not a submission. The pre-existing training_best_fixed solution always selects the training-best fixed method.

All source densities already require two PBE0 state SCFs and a B3LYP-prepared HS geometry. The sources provide a generation notebook and density-fitting code, but full fresh SCF/wavefunction reconstruction and end-to-end timing were not done. Candidate-method grid/PNO/custom-exchange recipes are only partly documented; method IDs identify fixed archived columns. This task measures method selection under supplied electronic inputs, not a proved cost advantage over a fixed method. The d4 singlet/quintet pair is the source convention and does not certify other spin states or the true ground state.

Eligibility retains source SCF/spin-contamination screening, HFX-curve cleaning, density availability, complete finite reference/all45 method gaps, and target-independent P2/P3 formula exclusion. The density notebook requires cleaned finite PBE HFX25; the source cleaner omits a point if removing it changes the interpolating curve by more than 5 kcal/mol. Same-named identifiers, atom counts, group-code sequence and padding are checked; shared P/N, S/O, Cl/F codes do not independently prove actual-element order within groups or every wavefunction coordinate. No CSD example is redistributed. FEATURE_RECIPE.md details the channels, inverse scaling, upstream selection and association limits. The original undefined181 descriptor remains unresolved.

The paired formula-cluster bootstrap intervals for density improvement over fixed and geometry baselines cross zero ([-0.39499370465289063,1.5075909866516564] and [-0.18792933564899042,1.0597694115765188] kcal/mol). Superiority is not established on this 58-record cohort. Training/final formulas and P2/P3 formulas are disjoint, while P1/P5 final records may overlap. Targets were public and inspected during construction; no pristine holdout or experimental/CC exactness claim is made.

The current state-metadata-complete scorer passes offline Linux inference and trusted scoring for the density and geometry models and the training-selected fixed method, eight malformed responses, deterministic replay, a target-free isolation-boundary probe and an independent error/oracle/regret fixture. measured/linux_report.json and measured/results/ contain these checks. Tests use a compatible CPU container and public-API VerifyContext double, not the private operator SDK/image. Actual operator SDK/image and root/chroot/setuid/syscall-isolation capability require technical review before merge; missing isolation fails closed. Offline single-process inference has 1800 s wall and 4 GiB address-space caps. Numeric NPZ weights require no source pickle or third-party trained model.
